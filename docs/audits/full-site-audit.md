## 检查方式

生产构建、TypeScript、ESLint、页面 HTML、唯一标题/H1、canonical、内部链接、锚点去重和本地图片存在性检查。浏览器从生产文件拦截加载页面，验证真实 hydration、完整文档导航、筛选、拖拽、键盘放置、刷新恢复、排行榜切换和手机宽度；不会启动项目服务。

`npm run audit:content` 重新完成 6,566 项与原始数据及计算函数的比对。玩法数据对应 **v0.8.13 / mvilprw2**；更新历史和官方榜单对应 **v0.8.25**。未把旧战斗定义冒充为最新版本实测结果。

最终结果：生产构建与 TypeScript 通过，ESLint 无错误/警告；13 项浏览器检查全部通过。构建审计覆盖 21 个内容 URL、1,625 个内部链接和 1,962 个图片引用，锚点无重复；741 个关闭详情的构建响应元数据均为 404。

新的页面截图位于 `test-results`。原始官方榜单的可访问性记录在忽略的 `docs/research/leaderboard-*-2026-10-23.txt`；可通过解析脚本重建数据。JSON 数据和脚本均没有虚构选手、成绩或排行榜差值。

旧 `all-page-browser-verification.json` 属于详情页关闭之前的 772 URL 历史检查，不能当作本轮页面数量。旧版 13 篇攻略和 12 伙伴排名已由当前 3 篇攻略、79 技能组分析替换。

离线检查不代表验证了部署主机的 HTTP/CDN、在线图像优化器、账户流程或每种构筑的实战胜率。排行榜明确标记采集日期，强度分数明确标记编辑模型。
