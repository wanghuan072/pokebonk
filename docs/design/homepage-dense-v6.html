ABOUT THE GAME

One more run, with a better plan.

PokeBonk is a browser survival game set among Kanto’s 151 Pokémon. Choose a partner, survive the hordes and build around the upgrades you find. This independent fan guide helps you compare kits, discover move fusions and plan permanent Lab upgrades.
